# Auction Service - ЛР1

Auction Service автоматизирует учёт аукционов, лотов и результатов продаж через HTTP API.
Версия проекта: `v0.1.0`.

## Возможности MVP

- регистрация продавца и покупателя;
- создание аукциона и добавление лота;
- переход аукциона `DRAFT -> OPEN -> CLOSED`;
- переход лота `DRAFT -> AVAILABLE -> SOLD/UNSOLD`;
- транзакционная регистрация продажи;
- запрет повторной продажи одного лота;
- отчёт по количеству продаж и выручке
- просмотр списка лотов выбранного аукциона;

После запуска доступны:

- Swagger UI: <http://127.0.0.1:8000/docs>
- health-check: <http://127.0.0.1:8000/health>
- readiness-check: <http://127.0.0.1:8000/ready>

## Основные команды

```bash
make setup    # создать .venv и установить зависимости
make migrate  # создать таблицы SQLite
make run      # запустить API
make test     # запустить тесты
make quality  # запустить Ruff
make verify   # quality + test
```

## Структура

```text
app/
  main.py       # маршруты FastAPI и обработчики ошибок
  schemas.py    # форматы запросов и ответов
  services.py   # SQL и бизнес-правила
  db.py         # подключение и создание SQLite
schema.sql      # реляционная схема
tests/          # автоматические тесты
docs/           # ТЗ, API, модель данных и материалы защиты
```

## Главное бизнес-правило

Продажа возможна только для доступного лота открытого аукциона, активному
покупателю и по цене не ниже стартовой. Вставка продажи и смена статуса лота
на `SOLD` выполняются в одной транзакции `BEGIN IMMEDIATE`. Уникальное
ограничение `sales.lot_id` дополнительно запрещает повторную продажу.
Деньги хранятся целым числом копеек, поэтому ошибки `float` исключены.
